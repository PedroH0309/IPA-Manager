Instalação OTA pelo iPhone.

Teste o protocolo de instalação nativo do iOS com um aplicativo que já possua uma distribuição válida. Nenhum computador é necessário para usar esta página.

ⓘ

Não é um desbloqueio do iOS. Um manifesto não assina, aprova nem instala um IPA arbitrário. O dispositivo decide se aceita o aplicativo. Uma tentativa iniciada não significa instalação concluída.

Preparar o manifesto

Você precisa possuir um IPA já hospedado em HTTPS e autorizado para distribuição OTA.

Os dados são processados no seu navegador. O IPA não é enviado ao IPA Manager.

Manifesto preparadoLocal · não assinado

Salve manifest.plist e hospede-o em uma URL HTTPS pública. A hospedagem precisa oferecer o XML completo e permitir que o iOS baixe o IPA referenciado.
